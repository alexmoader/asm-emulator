# Ассемблер и эмулятор учебного процессора

Я написал на C++17 две утилиты для простой модели процессора с 16 32-битными регистрами. Ассемблер переводит текстовую программу в бинарный файл, а эмулятор читает команды и выводит итоговые значения регистров.

В [задании](TASK.md) описал набор команд и поведение утилит. Рабочие примеры лежат в папке [examples](examples/).

## Сборка и запуск

Нужны компилятор с поддержкой C++17 и CMake.

```sh
cmake -S . -B build
cmake --build build
./build/asm examples/prog1.s build/prog1.o
./build/emu build/prog1.o
```

В первом примере в регистр `R0` записывается `0x1`, затем это значение прибавляется к `R1`. Эмулятор выводит `R1=0x8001`. Второй пример складывает значения `R2` и `R3` и сохраняет сумму `0x30` в `R4`.

Код сборки команд находится в `src/assembler.cpp`, чтение и исполнение инструкций — в `src/emulator.cpp`.
